# 🔴 YouTube Clone

A simple **YouTube Clone** website created using **HTML and CSS**.

## 🔴 YouTube

The project is inspired by the original YouTube interface, using its familiar red branding and video-focused layout.

## ✨ Features

* 🔴 YouTube-style red logo
* 🔍 Search bar
* 🎥 Video cards
* 🖼️ Video thumbnails
* 📺 YouTube-style layout
* 🎨 Clean and simple design

## 🛠️ Technologies Used

* HTML5
* CSS3
